TCP Split

Разбивает TLS ClientHello на сегменты, чтобы DPI не собрал SNI целиком.

быстрыйlow-cpu

Fake TLS

Отправляет поддельный ClientHello с фейковым SNI впереди настоящего пакета.

обходит SNI-фильтр

Disorder

Меняет порядок сегментов + дублирует с низким TTL — сбивает реассемблер DPI.

агрессивный

Fake + Split2

Комбо: фейк-пакет с TTL-обманом, затем двойное разбиение. Топ против РКН-DPI.

сильный

QUIC Drop

Подавляет QUIC/UDP-443, форсируя fallback на обходимый TCP TLS.

DNS для ИИ-сервисов

ChatGPT · Claude · Gemini

Большинство ИИ блокируются не на уровне DPI, а по IP и геолокации — обычный обход их не открывает. Специальный DNS направляет такие домены через свои прокси и возвращает доступ. Применяется ко всей системе (нужны права администратора), сбрасывается выбором «Выключено».

О приложении

SSBZapret — это утилита обхода DPI с открытым кодом и собственным движком на базе WinDivert. Идея вдохновлена проектом bol-van/zapret — собрать сложные параметры обхода в простой, безопасный и красивый интерфейс. Stronger · Smarter · Better.
