# SSBZapret

**Stronger · Smarter · Better** — открытая графическая обёртка над движком обхода DPI [zapret](https://github.com/bol-van/zapret) от bol-van. Никаких `.bat`-файлов и ручных аргументов winws: пресеты под сервисы, кнопки, темы — открыл и пользуешься.

*Разработан при участии ИИ — Claude Opus 4.8.*

> ⚠️ **Без гарантий. Проект в активной разработке (work in progress).**
>
> Я **не даю никаких гарантий**, что софт работает на 100% — это сырая версия, которую я пилю в свободное время. Что-то может не запускаться, работать нестабильно или отваливаться после обновлений. Используете на свой страх и риск и **не как единственный способ** доступа к чему-то важному. Идеи и баг-репорты приветствуются.

## Чем это отличается от того, что уже есть

Движок один и тот же — bol-van. Дальше варианты:

- **Сам `zapret` / `zapret-win-bundle`** — консоль, конфиги, понимание матчасти. Официальная сборка прямо пишет: «это не однокнопочное решение».
- **Народные сборки** (Flowseal, «Discord Fix» от Хауди Хо и др.) — наборы `.bat`-файлов с готовыми стратегиями. Удобнее, но это всё ещё батники и отдельные утилиты.
- **«Zapret 2 GUI»** — самый раскрученный сторонний GUI [оказался вредоносным](https://habr.com/ru/articles/1015380/) (тихо ставил свой корневой сертификат).

SSBZapret пытается занять честную середину: **нормальный интерфейс на актуальном движке, открытый код и ничего лишнего в системе.**

## Что уже умеет

- Пресеты под популярные сервисы (ИИ, Discord, YouTube, соцсети, игры) + «Всё сразу»
- Несколько стратегий в одном запуске (chaining через `--new`) — разным группам доменов свой desync
- Свои правила и домены
- Подмена DNS (Comss, Xbox-DNS, Cloudflare, Google)
- 7 тем оформления, по умолчанию монохром
- Автозапуск и сворачивание в трей
- Встроенный авто-апдейтер: вышла версия → уведомление → «Обновить» → само скачалось, поставилось, перезапустилось

## Что в планах

- Большие регулярно обновляемые hostlist'ы
- Обход по IP-диапазонам (`--ipset`) — голос Discord, игры
- Автообновление списков и базы стратегий
- fake-payload из реальных `.bin`-слепков
- Умный автоподбор с реальными проверками по каждому сервису

## Установка (для обычных пользователей)

Ничего собирать не нужно — просто:

1. Скачай последнюю версию из раздела [Releases](../../releases).
2. Запусти `SSBZapret-setup.exe` и пройди установщик.
3. Готово. Приложение работает сразу и само предложит обновление, когда выйдет новая версия.

> Rust, Node и прочие инструменты разработчику ставить **не надо** — всё уже внутри установщика.

## Сборка из исходников (только для разработчиков)

> 🛠️ Этот раздел нужен, **только если ты хочешь собрать приложение сам** (внести правки, проверить код, сделать свою сборку). Обычным пользователям он не нужен — см. «Установка» выше.

Понадобятся **Rust** и **Node.js**:

```bash
npm install
npm run tauri build
```

На выходе получится тот самый `.exe`-установщик в `src-tauri/target/release/bundle/`.

Бинарники winws (`winws.exe`, `cygwin1.dll`, `WinDivert.dll`, `WinDivert64.sys`) нужно положить в `src-tauri/resources/` — берутся из [zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle).
